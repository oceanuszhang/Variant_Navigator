# VariantNavigator runs on the Python 3.11+ standard library alone.
#
#   python main.py --test-case all
#   python -m pipeline.baseline
#   python -m pipeline.pocket
#   python scripts/make_figures.py
#
# All of the above need NO pip install and NO API key. Network access to
# UniProt, PubChem and RCSB PDB is the only external dependency, and all three
# are public and keyless. HTTP is urllib; figures are hand-written SVG; the
# pocket maths is the math module. This is deliberate — it keeps the demo
# install instant and removes the usual cause of a dead hackathon laptop.
#
# Nothing is pinned here because nothing is imported. Verify with:
#   grep -rE '^\s*(import|from) ' main.py pipeline/ scripts/
#
# ---------------------------------------------------------------------------
# Previously listed and removed, because no module imports them:
#   requests  - superseded by urllib in fetch.py / pocket.py
#   rdkit     - SMILES are consumed as opaque strings; this was a slow build
#               for nothing
#   modal     - only named in a config string in esm2_score.py, never imported
# Re-add them in the extras below if and when the stubs are actually wired.
# ---------------------------------------------------------------------------
