Active ABL1 / imatinib dataset

Measured labels

Inam, Tomaszkiewicz, Reynolds, Yang, Leighow & Pritchard (2025)

Characterizing Variants of Uncertain Drug Resistance (VUDRs) Using Quantitative Measurements at Clinical Exposures. bioRxiv preprint, version 1, November 3, 2025. DOI: 10.1101/2025.10.31.685392 · Full text

The pipeline loads the authors' Figure 2D high-imatinib net-growth table: netgrowth_mean_corrected and corrected replicate columns at 1,200 nM imatinib. The local loader contains 4,925 variant rows; this is a file-specific count, not a claim about every analysis population in the paper.

  • Authors' data and analysis repository — repository license: MIT; the paper has separate publication terms.
  • Source CSV: high_imatinib_netgrowth_data.csv — cached locally as data/datasets/abl_dms_netgrowth_1200nM.csv.
  • Related IC50 estimates — available upstream; not the response target used by this UI.

Net growth combines protein function and response under drug. It is not a direct clinical efficacy measurement. Literature is kept separate from prediction features.

Sequence, structures & compound records

Reference data
  • UniProt P00519 — ABL1: protein identity and sequence reference. The current runtime uses the checked-in 518-aa file data/cancer-exp/ABL1_NM_005157.6_DMS_reference_aa.txt; its filename identifies the reference, but is not itself a provenance checksum.
  • NCBI RefSeq NM_005157.6: transcript record named by the local reference file. Retain the exact sequence hash and numbering used for each trained run.
  • RCSB PDB 1IEP — ABL kinase / STI-571 complex: experimental pocket geometry used by the handcrafted-feature path. 2HYY is an additional recorded ABL/imatinib reference. Consult each entry's primary citation.
  • PubChem CID 5291 — imatinib: compound identity. Broader drug-panel SMILES and CIDs are recorded in data/drug_panels/ and data/compounds/compounds.json.

Supporting model & feature methods

Methods, not labels
  • Lin et al. (2023). Evolutionary-scale prediction of atomic-level protein structure with a language model. Science. DOI: 10.1126/science.ade2574. ESM-2 supports the saved embedding-based benchmark; this citation does not imply that the local runtime RandomForest uses ESM features. Model implementation and checkpoints.
  • scikit-learn RandomForest: the current unmeasured-variant inference path. Ridge and histogram gradient boosting document the saved benchmark heads.
  • pipeline/features.py records embedded BLOSUM62 substitution scores, Kyte–Doolittle hydropathy, side-chain volume and charge features. Consult the feature definitions when interpreting runtime estimates.

Broader repository sources

Outside this UI's benchmark
  • Target sequences: EGFR P00533, rice ALS1 Q6K2E8, and Arabidopsis ALS P17597. Accessions and numbering offsets are recorded in data/targets.json; older controls pin their own accessions in data/test_cases/.
  • Experimental structures: 1M17 and 4ZAU for EGFR; 1Z8N and 1YHZ for Arabidopsis ALS. ALS ligand distances are approximate proxies for the rice compounds.
  • Planned EGFR IC50 and rice GR50 tables are described in data/datasets/SCHEMA.md. Their exact source-paper citations are not specified there and remain unresolved; they are not presented as active training data.
  • PubChem supplies compound records for the legacy panels. Paperclip supplies separately retrieved literature when invoked by the pipeline; any result-specific papers should accompany that report, rather than being treated as training labels.

This bibliography identifies sources used or explicitly recorded by the repository. It is not an exhaustive bibliography of resistance biology. Saved validation provenance and artifact SHA-256 are available in Run overview.
